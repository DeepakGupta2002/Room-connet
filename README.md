# RoomConnect

No-broker room listing and discovery platform for India.

RoomConnect lets verified users browse rooms without login, while tenants and owners can submit listings. Contact access requires OTP login and an unlock action. Only the verified and consented owner contact may be revealed; tenant phone numbers are never exposed.

## Current status

This repository currently contains the product specification and screen definitions. Application code, migrations, APIs and deployment configuration are not implemented yet.

## Product decisions

- Tenant and owner listings are allowed.
- Broker, agent and caretaker listings are not allowed.
- Browsing and searching work without login.
- OTP/login is required to unlock an owner contact.
- Owner approval is optional for the MVP and can become mandatory later.
- Tenant phone numbers are never shown.
- Donation is optional; donor access lasts 30 days and still has a configurable daily unlock limit.
- Listing slugs are generated by the backend.
- Listing expiry is based on `expires_at`, normally leaving date plus 15 days.

## Screen specifications

The `screen-specs` directory contains separate JSON files for public seeker screens, tenant/owner flows and admin/moderation screens. All files are mobile-first and include responsive behavior, privacy rules, states and intended API actions.

## Security principles

- Never commit `.env`, API keys, OTPs, passwords or payment secrets.
- Store OTPs and tokens as hashes.
- Encrypt sensitive contact data and keep a separate normalized blind hash for uniqueness.
- Keep private contact data out of public listing responses.
- Enforce ownership, role checks, rate limits and audit logs on the backend.
